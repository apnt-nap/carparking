# Thai Mall Parking (prototype)

A mobile app that finds free parking at Thai shopping malls, running on **simulated data**.
The spec is [SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md), and the build plan is [CLAUDE_CODE_PROMPT.md](CLAUDE_CODE_PROMPT.md).
Non-obvious choices are explained in [DECISIONS.md](DECISIONS.md).

## Layout

| Folder | What |
|---|---|
| `server/` | Mock API server (Node.js, Fastify, `ws`, TypeScript) |
| `server/data/malls.json` | Five sample malls (hand-written, sample data) |
| `server/data/floors.json` | Floor plans and bays, generated by `server/scripts/generate-floors.ts` |
| `app/` | React Native + Expo app (Milestone 2, not started yet) |

## Run the server

Needs Node.js 20 or newer.

```bash
npm install          # from the repo root
npm run server       # http://localhost:3000, reloads on change
```

Try it:
- http://localhost:3000/malls?lat=13.7462&lng=100.5347
- http://localhost:3000/malls/siam-paragon
- http://localhost:3000/floors/siam-paragon-b1
- http://localhost:3000/search?q=พารากอน&lang=th
- WebSocket: `ws://localhost:3000/live?floor=siam-paragon-b1`

Environment variables: `PORT` (default 3000), `SIM_INTERVAL_MS` (simulator tick, default 3000), `PLATE_HASH_SALT` (salt for hashed plates in logs).

To regenerate floor plans after editing `malls.json`: `npm run generate -w server`.
