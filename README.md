# Thai Mall Parking (prototype)

A mobile app that finds free parking at Thai shopping malls, running on **simulated data**.
The spec is [SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md), and the build plan is [CLAUDE_CODE_PROMPT.md](CLAUDE_CODE_PROMPT.md).
Non-obvious choices are explained in [DECISIONS.md](DECISIONS.md).

## Layout

| Folder | What |
|---|---|
| `server/` | Mock API server (Node.js, Fastify, `ws`, TypeScript) |
| `server/data/malls.json` | Five sample malls (hand-written, sample data) |
| `server/data/floors.json` | Floor plans and bays, generated by `server/scripts/generate-floors.ts` |
| `app/` | React Native + Expo app (Expo Router, TypeScript) |
| `app/src/app/` | Screens: map, search, settings, mall, floor |
| `app/src/lib/route.ts` | Shortest route on the one-way lane graph (FR-12) |

## Run the server

Needs Node.js 20 or newer.

```bash
npm install          # from the repo root
npm run server       # http://localhost:3000, reloads on change
```

Try it:
- http://localhost:3000/malls?lat=13.7462&lng=100.5347
- http://localhost:3000/malls/siam-paragon
- http://localhost:3000/floors/siam-paragon-b1
- http://localhost:3000/search?q=พารากอน&lang=th
- WebSocket: `ws://localhost:3000/live?floor=siam-paragon-b1`

Environment variables: `PORT` (default 3000), `SIM_INTERVAL_MS` (simulator tick, default 3000), `PLATE_HASH_SALT` (salt for hashed plates in logs).

To regenerate floor plans after editing `malls.json`: `npm run generate -w server`.

## Run the app

Start the server first (above), then in a second terminal:

```bash
npm run app          # Expo dev server; scan the QR code with Expo Go
```

- **Expo Go** works for everything except voice search: the map, malls, floor plans, live bays, routing, Thai/English and "I parked here". The mic button explains that voice needs a development build.
- **Development build**, which includes voice search (FR-17): `cd app && npx expo run:android` or `npx expo run:ios` (needs Android Studio or Xcode), or `npx eas-cli@latest build --profile development`.
- The app finds the server automatically at the dev machine's address on port 3000. To use another address, set `EXPO_PUBLIC_API_URL=http://<ip>:3000` before `npm run app`.
- **Using WSL on Windows:** a phone can't reach a server inside WSL by default. Either run `npm run app` with `--tunnel` and set `EXPO_PUBLIC_API_URL` to an address the phone can reach, turn on WSL mirrored networking (`networkingMode=mirrored` in `.wslconfig`), or run both commands from Windows PowerShell.

## Tests

```bash
npm test             # Vitest (server) + Jest (app)
npm run typecheck    # tsc --noEmit for both
```
